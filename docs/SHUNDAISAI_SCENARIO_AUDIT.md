| 気骨稜稜 | 常磐なる誓い | 단거리 스킬 2개 보유 + 본행사 대성공 |

여섯 종 중 최대 **2개**만 선택한다. 육성마의 본체 진화는 이 제한에 포함하지 않는다.
원본 금색도 후보로 유지하여 시나리오 진화 슬롯을 받지 않은 스킬을 금색으로 살 수 있게 했다.
동일 원본의 금색/진화 중복 구매는 기존 스킬 계열 배타 규칙으로 막는다.

제한은 수동 체크·전체 선택·고정, 스킬 최적화, 구매 가능성 검증, 편성 추천에 적용한다.
진화 조건은 기존 프로젝트 정책대로 충족을 가정한다. 특히 거리별 스킬 2개 조건을
최종 구매 목록으로 자동 증명하는 기능은 추가하지 않았다. 이 한계는 데이터·화면에 명시한다.

## 구현 범위 및 남은 한계

- `assets/acquisition-rules.mjs`: 본체/서포트 캐릭터 링크, 이벤트 보상 구체화, 진화 개수 제한을 공유한다. 미구현 조건은 허용하지 않는다.
- `candidates.mjs`·`purchases.mjs`: 같은 링크 판정으로 후보와 실제 가격·획득 경로를 구성한다. 시나리오 선택도 카드 선택과 같은 이벤트 상태 탐색에 넣는다.
- `selection.mjs`·`skill-optimizer.mjs`: 진화 2개 제한과 금색 대체 후보를 적용한다.
- `app.mjs`·`display.mjs`: 시나리오 이벤트 선택과 계획 내보내기에 시나리오명·사건명을 표시한다.
- Python 정규화/검증: 시나리오 보상·조건·선택과 생성 경로의 일치, 진화 제한의 참조를 검사한다.

이벤트 완주·발표회 및 본행사 대성공·굿 엔딩·진화 조건 충족을 가정한다.
실제 훈련/게이지/발표회 성공 확률 또는 예상 스탯·SP를 시뮬레이션하지 않는다.
`名にし負う夢`의 연목 레벨에 따른 `value_scale=41` 효과는 기존 계산 미지원 상태를 유지한다.
획득·가격은 기록하지만 임의의 고정 효과량이나 0마신으로 자동 추천하지 않는다.
다른 시나리오의 보상과 진화 개수 제한은 이번 변경의 범위 밖이다.
이벤트 상태·스킬·편성 최적화는 기존의 제한된 탐색 정책을 유지하며 전역 최적을 보장하지 않는다.
