세 영역은 공통 계산을 사용하지만 기준 조합과 목적이 다르다. 단독 표의 상위 행이 그대로 최종 추천이 되는 구조가 아니다.
개정4의 압축 변경은 주로 최종 추천의 탐색·평가 비용을 바꿨다. 공통 평가기에도 표본 재사용을 추가했으나,
같은 조합의 마신·HP·발동 수치를 바꾸는 수식 보정은 추가하지 않았다.

### 후보·구매·연계의 보존

- 능력치 때문에 현재 비활성인 후보도 획득 가능성과 분리해 보존하고, 실제 육성 능력치로 다시 판정한다.
  힌트·습득 기록을 유지하며 상위를 제거하면 이미 습득한 하위 효과를 복원한다.
- 실제 힌트·할인 특성·기구매 하위를 반영한다. 공통 구매 단계는 한 번만 청구하고 미검증 비용을 무료로 취급하지 않는다.
- 이벤트 선택의 동시 획득 가능성, 진화 분기, 시나리오 진화 최대2개와 계승 최대6개를 검사한다.
- 회복·HP·보유/사용 참조·발동 개수 등은 전체 조합에서 계산한다. 단독 기여가 작거나0이라는 이유만으로 연계 후보를 버리지 않는다.
- 추천에 맞추기 위한 스킬명/ID별 금지 분기나 점수 가산·감산 계수를 추가하지 않는다.
  원본에 명시된 개별 효과와 검증된 변환 규칙은 데이터 근거로 구분한다.

더 싼 조합을 선택해 생긴SP로 추가 구매가 가능해지면 다시 검사한다.
작은 개선을 여러 개 묶은 제안도 전체 주행으로 검증한다.
`gainTolerance:0`은 압축·예비 선별을 끈 정밀 비교 경로다. 큰 문제에서는 이 경로도 전역 최적성을 보장하지 않는다.

## 4. 남은 한계와 해석 기준

**0.1마신은 현재 평가 표본에서 완전 평가한 최선에 대한 선택 허용 범위다.**
다음 세 가지는 서로 다르다.

1. **선택 허용 범위:** 같은 HP·위험 우선순위에서 관측한 최선보다 얼마나 양보해SP를 절약하는가.
2. **탐색 누락:** 정밀 평가하지 않은 조합에 더 좋은 해가 있을 가능성.
3. **표본·모델 차이:** 시드·표본 수·시간 간격·전개 가정·미검증 수식에 따른 결과 변화.

현재의0.1이2·3까지 합친 전역 오차 상한은 아니다.
고정 추천을 다른 설정에서 비교한20대조 중4건은 약0.1168~0.1250마신 낮았다.
이때도 표본HP 충족률과 부진 구간 보호는 유지됐지만, 모든 추첨에서0.1 이내라고 설명할 수는 없다.
현재 반별 평균 차이를 통계적 신뢰구간으로 취급하지 않는다.

왕수·군림 같은 조건부 가속은 원본 발동 조건과 공통 주행으로 평가한다.
금지된 조건의 차단과 실전에서 유효하게 발동할 빈도의 검증은 별개다.
과거 감사에 남은 군림의 제한 후보군 선택 사례와 미실측 전개 한계를 이번 속도 개선이 해소했다고 선언하지 않는다.
이름별 감점 대신 조건·기회·상태 변화·유효 가속 구간을 공통 규칙으로 다뤄야 한다.

과거25코스·37조건 재실행은 **고정v11**의 기록이다. 현재v14를 그 전 범위에서 새로 검증한 숫자로 합산하지 않는다.
관련 원자료는 [v11 테스트베드](CM_TESTBED_REVALIDATION_V11.md),

실제 상대 주행·실측 전개 분포·승률 모델과 일부 게임 수식의 근사는 기존 한계로 남긴다.

### 표본 안정성 개선에서 지킬 점

- 모든 후보를 일괄적으로576표본까지 계산하기보다, 최종 경쟁 후보에 계산을 집중한다.
- 같은 표본 번호·전개 가중치로 조합 간 차이를 비교하고 기존 관측값을 재사용한다.
- 여러 표본에서도0.1을 목표로 할지, 불안정함을 표시하고 기존 기준을 유지할지 정책부터 명시한다.
  신뢰구간을 도입하려면 표본 설계·의존성과 추정 가정을 먼저 검토한다.
- 최종 표본 수나 선택 정책을 바꾸면 모델 식별자·내보내기·검증 기준도 함께 갱신한다.
  이는 현재의144표본 계약에 자동으로 포함된 기능이 아니다.

### 추가 성능 개선에서 지킬 점

초기/후속 작업량을 함께 줄인 시험은158초까지 빨라졌지만0.311마신 손실로 채택하지 않았다.
반대로 넓은 재검토는 기여를 높이면서 시간을 늘렸다. 새 변경도 같은 품질·시간의 교환 관계를 측정해야 한다.
특히 SP를 아낀 뒤 새로 가능한 구매를 재검토하는 절차와 작은 변경의 묶음 검증을 다시 없애지 않는다.
단순 마신 반올림이나 개별0.1 미만 후보 삭제로 전체 조합의 누적 이득을 버리지 않는다.
캐시를 확대할 때도 다른 입력·조합·시간 간격의 관측을 잘못 공유하지 않도록 한다.

- 근거 없는 데이터 검증 완료 처리, 미지원 효과를0점으로 숨기기, 획득·진화 해금의 자동 달성 가정.

실제 전개 관측이나 새로운 원본 근거가 생기면 별도 검증 과제로 다룬다.
