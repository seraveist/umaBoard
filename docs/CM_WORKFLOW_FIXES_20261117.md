# 육성·CM 흐름 5개 보완 결과

2026-11-17 (Asia/Seoul). [이전 점검](CM_WORKFLOW_AUDIT_20261117.md)의 5개 항목을 제품에 적용했다.
계산 모델은 1차 `cm-first-chart-v6`, 목표 `cm-target-acceleration-v4`, 최종 `cm-post-training-v9`이며
공통 순위 비교는 `cm9-fixed-rank-sensitivity-v2`, 전략 정책은 `cm-strategy-v1`이다.

## 변경 내용

| 항목 | 실제 동작 |
| --- | --- |
| HP 발동 조건 | 1차·목표·최종의 `hp_per`를 유지한다. 실제 주행 HP로 발동하고 최대HP 회복 낭비를 반영한다 |
| 기존 구매 이력 | `미습득 전체 Lv5`는 `owned`를 보존한다. 숨겨진 기존 진화 이력과 Top10 밖으로 밀린 기록 계승도 보존한다 |
| 순위 비교 | 세 단계가 같은 순위별 비교 평균을 쓴다. 최종 기준은 실제 습득 효과이며 HP는 비교 순위·표본 전체에서 검사한다 |
| 시나리오 레어 | 카드와 시나리오의 레어 선택을 같은 가속 목표 아래 함께 비교해 육성 전에 표시한다. 실제 최종 구매는 실제 힌트로 제한한다 |
| CM 전략 | 적용 조건의 PDM 핵심을 확보 목표로 표시하고, 확보한 경우 최종 구매에서 기본 유지한다. 사용자가 유지 해제 가능하다 |

화면의 두 번째 단계는 **최종 구매·진화**로 바꿨다. 모든 육성 보상을 받은 뒤 인게임 육성 완료를
확정하기 전에 사용하도록 안내한다. 구매와 진화는 여전히 한 조합으로 탐색하고 결과만 영역별로 나눈다.

## PDM 확보·구매 정책

- 적용은 **잔디2200m 이상·선행/선입/추입**의 우선 확보 정책이다. 도주·2000m 이하·더트에 일괄 강제하지 않는다.
- 목표는 `ウマ好み`와 같은 역할을 유지하는 상위·진화형이다. 초기 발동 구간을 잃은 진화는 PDM 대체로 인정하지 않는다.
- 직접 속도 효과는 기존 마신으로 계산하고 PDM 해제의 미측정 추가 마신은 만들어 넣지 않는다.
- 실제로 확보한 후보 중 낮은 구매 비용의 단계를 우선 유지하고, 같은 역할의 상위형으로 승급할 수 있다.
  보유한 금색의 구매 하위 단계가 가능하면 그 하위를 Lv0으로 살 수 있다. 별도 하위 힌트를 받았다고 기록하거나 Lv5로 할인하지 않는다.
- 미획득 스킬은 생성하지 않는다. 미확보·다른 고정과 충돌한 목표를 결과에 표시한다.
  SP가 부족하면 목표/전략 유지 제약을 해제해 다시 비교하도록 안내하고 자동으로 해제하지 않는다.
- 본체 고유기 등 다른 PDM 해제 수단을 활용하는 사용자는 전략 유지 옵션을 해제할 수 있다.
- 시나리오 선택으로 PDM을 얻는 경로도 별도 안내한다. 기본 편성의 오식준대제에서는 다른 경로에서
  `ウマ好み`를 못 얻었을 때 `本番前のひと時`의 블래스트 원피스 선택이 대안이다.
  같은 이벤트의 추천 레어와 동시에 선택할 수 있다고 표시하지 않는다.
- 동급 레어의 중반 보강은 기존 종반 진입 시점의 위치 이득 보조 기준을 유지한다.

이 범위는 출처가 있는 준비 정책이며 9인 전개·PDM의 발동 확률·승률을 예측한 공식이 아니다.
중반 위치 경쟁이나 다른 전략의 가치를 임의의 마신 보너스로 추가하지 않는다.

## 검증 결과

[수정 후 진단](validation/cm-workflow-v4-20261117.json)과
[실제7000 SP 연결](validation/cm-acceleration-v4-7000-20261117.json)에 입력·모델·소스 해시를 보존했다.
수정 전 진단 JSON은 덮어쓰지 않았다.

- 실제 장거리 `火事場のバ鹿力`·`別腹タンク`: 0초 대신 HP30% 조건의 **107.2초**에 발동한다.
- 통제 순위 반례: 각 고정 순위에서 양립 불가 두 효과의 동시 발동은0건이며,
  최종 추천 점수와 공통 순위 비교의 차이는0이다.
- 실제7000 SP 사례도 같은 선택의 최종 점수와 공통 비교 점수 차이가0이다.
- 오식준대제 링크 선택은 마야노·아즈마 레어 대안을 비교해 사전에 표시한다.
  실제 사례는2번 `順風満帆`을 목표로 정하고 해당 이벤트 경로만 실제 힌트로 기록한 뒤 최종 계산했다.
- 일괄Lv5 후 기존 구매 단계는0 SP를 유지한다. 실제 습득·힌트가 새 계승Top10 밖으로 밀려도 기록을 유지한다.
- 강한 단독 마신의 대안이 있어도 PDM 핵심을 보호하며, 보호 해제·미획득·SP 부족·금색의 하위 구매·초반 역할을 잃은 진화를 각각 검사한다.
- 실제 중산2500m에서 HP 조건 금색 회복과 PDM 보호를600 SP 안에서 함께 처리하는 검사를 통과했다.
- 전체 Node254개·Python56개 통과 후 실제 중산 사례1개를 추가 검증했다. 최종 합계는 **Node255개 + Python56개 =311개**다.
- 정적 Pages 빌드·데이터 검증·기존 의상274/SSR319 이미지 배포를 확인했다.

실제7000 SP 사례: **6996 SP 사용·4 SP 잔여·계승6개·시나리오 진화2개·목표 가속13개 유지·PDM 유지·모델상 HP 충족**.

제한 탐색의 지역적 수렴을 확인했으며 전역 최적해나 실전 승률 보장은 아니다.
