# 가속 목표와 연결한 계승·프렌드 인자 준비 — 설계안

상태: **보류·현재 작업 범위에서 제외**. 사용자가 가속 추천 개선과 계승 제공자
아이콘 표시만 우선하기로 했다. 아래는 향후 검토용 설계 기록이며 구현하지 않는다.

2026-11-17 사용자 요청: 추천 가속 조합과 추천 계승 조합을 연결하여, 육성 전
부모로 빌릴 프렌드 인자를 찾는 데 사용할 수 있게 한다. 이 문서는 구현 계약이며
아직 계산·화면에 적용된 기능은 아니다.

## 목적과 출력

1차 마신표의 하단을 `추천 가속·계승 준비` 영역으로 확장한다.
개별 계승기 Top10은 비교 자료로 유지하고, 별도로 **부모2명 조합**과 검색 메모를 제공한다.
단순히 가속 계승기를 고정한 뒤 남는6칸을 속도 순위로 채우지 않는다.

| 영역 | 표시 내용 |
|---|---|
| 목표 가속 | 본체 고유·각성 진화, 일반/레어 가속, 직접 부모의 가속 역할 |
| 추천 부모2명 | 정확한 의상·고유명, 가속/중반/종반 역할, 선택 이유, 강화 조건 |
| 부모 대안 | 기본 조합과 함께 가속 보강형·속도 보강형 등 근거가 다른 소수 대안 |
| 조부모 후보 | 최대4자리 보완 후보, 우선순위, 계승 성공 시 추가 이점 |
| 프렌드 검색 메모 | 빌릴 부모 의상, 희망 조부모, 우선 흰 인자, 대체 가능한 조건 |
| 서포트 레어 세트 | 같은 부모 조합과 가속 목표를 사용한 추천 |

프렌드 검색 메모는 검색에 필요한 목표를 복사하는 기능으로 정의한다.
실제 프렌드DB 검색·계정 추천·검색 결과 존재 확인은 별도 연동 전까지 포함하지 않는다.

## 실제 계승 제약

- 직접 부모2명의 유효 고유 힌트는 시작 시 확보한다. 조부모4명의 고유는 육성 중
  확률 계승이다. 부모만 확보한 경우와 조부모까지 계승된 경우를 같은 점수로 표시하지 않는다.
- 강화 계승기는 해당 의상을 직접 부모로 두고, 본인이 해당 의상을 보유하는 등
  스킬별 강화 조건을 충족해야 한다. 프렌드 대여만으로 보유 조건을 만족하지 않는다.
- 보유·강화 조건이 미확인이면 조건부로 표시한다. 일반형을 대체로 평가하고,
  강화형이 무조건 가능한 상태로 원본을 제거하지 않도록 후보 정책을 보완한다.
- 직접 부모는 육성 본체와 동일 캐릭터, 서로 동일 캐릭터인 조합을 제외한다.
  고유가 의상별로 다르므로 제공 의상을 이름과 함께 표시한다.
- 대여는 한쪽 부모에 적용한다. 다른 부모는 사용자가 준비해야 한다.
  보유 부모 정보가 없으면 임의로 자가·대여를 확정하지 않는다.
- 하나의 부모 개체를 빌리면 그 개체의 조부모2명도 함께 정해진다. 후보 조부모4명을
  아무렇게나 재배치할 수 있다고 표시하지 않는다. 실제 개체를 고정한 뒤에는 그 계보를 사용한다.
- 기존 계승6개 제한은 부모·조부모 전체에서 얻을 수 있는 후보의 상한이다.
  6개 전부를 확정 확보하는 것으로 해석하지 않는다. 동명·계열 중복도 합산하지 않는다.

## 계산 순서

1. 본체와 편성의 가속, 가능한 일반 계승·강화 조건을 구성한다.
2. 부모2명 후보 조합마다 **그 두 고유를 확보 가능 상태로 둔 가속 목표**를 계산한다.
   강화 조건, 이벤트 배타, 중복 계열, 동일 시점 순위 조건을 검사한다.
3. 부모 가속이 늘면 일반 가속의 필요량도 다시 비교한다. 반대로 본체·서포트 가속이
   충분하면 부모 한쪽 또는 양쪽을 속도 계승으로 바꾼 대안을 비교한다.
4. 마신은 두 고유의 단독 값을 더하지 않고 함께 주행한 한계효용으로 평가한다.
   동급이면 안정적인 발동 조건을 우선하고, 전방 순위 조건이 있는 조합에서는
   중반 보강을 보조 기준으로 사용한다. 실전 순위 예측값으로 표기하지 않는다.
5. 선택한 부모2명의 확정 확보를 기준으로 서포트 레어 세트를 다시 계산한다.
   조부모 고유의 획득을 전제로 필수 이벤트 선택을 고정하지 않는다.
6. 조부모 후보는 확보 시의 추가 효과를 비교해 별도 제시한다. 확률 모델과 계보가
   검증되기 전에는 임의의 성공률·기대 마신을 곱하지 않는다.
7. 현재 편성에서 확보하기 어려운 목표 일반 스킬을 흰 인자 우선 조건으로 표시한다.
   금색·진화형 자체를 흰 인자로 요청하지 않고, 확인된 하위 일반형을 연결한다.

이 순서는 일반/레어 가속 목표와 부모2명 선택을 함께 조정하기 위한 것이다.
육성 전 총SP 예측이나 실제 부모 개체의 상성 점수·교배 확률 최적화로 확대하지 않는다.

## 입력과 사용자 흐름

- 기존 레이스·본체·각질·시나리오·편성을 사용한다.
- 선택적으로 자가 부모1명을 고정하면 그 부모와 맞는 대여 후보를 추천한다.
- 강화형이 후보에 있을 때 해당 의상의 보유 조건을 확인할 수 있게 한다.
  전 우마무스메 보유 목록 입력을 요구하지 않는다.
- 부모 조합을 바꾸면 가속·계승·서포트 레어 세트 추천을 함께 갱신한다.
- 프렌드 검색 메모에는 `우선 조건`과 `있으면 좋은 조건`을 나누어 너무 희귀한
  한 개체를 모든 조건 필수로 찾게 하지 않는다. 일반 흰 인자도 항상 확정 계승은 아니다.
- 육성 후에는 실제 확보한 고유·힌트만 최종 SP 계산에 사용한다. 추천 부모 또는
  조부모 목록을 실제 습득 기록으로 자동 입력하지 않는다.

## 화면 형식 예시 — 최종 추천 결과 아님

교토2200 선행에서 본체·편성을 확정하고 재검증한 뒤 다음 형식으로 출력할 수 있다.

| 항목 | 예시 |
|---|---|
| 부모 후보 | 에피파네이아 + 정월 키타산 블랙 |
| 역할 | 강화 계승의 중반 속도·종반 가속 + 전방 조건 종반 가속 |
| 직접 부모 조건 | 에피파네이아 강화형은 본인 보유 및 직접 부모 배치 확인 |
| 조부모 후보 | 두 부모만으로 가속이 충분하면 중반·종반 속도 보완 후보 제시 |
| 흰 인자 우선 | 직활강 등 현재 편성에서 확보하기 어려운 목표 일반 가속 |
| 검색 메모 | 자가 부모를 고정한 경우 남은 부모 의상과 희망 조부모·흰 인자 목록 |

## 선행 보완과 기존 코드 연결

- [외부 공략10조건 검증](CM_ACCELERATION_EXTERNAL_AUDIT_20261117.md)에서 발견한
  강화 계승 구매 단계 연결, 순위 조건 동시 실현 가능성, 탐색 후 추가·교체 검증을 먼저 해결한다.
- `cm-chart.mjs`의 표시 Top10 이전 계승 후보 및 `inheritance_outfit_ids`를 사용한다.
- `cm-acceleration-plan.mjs`는 부모2명과 계승 조건을 받은 같은 기준으로 목표와 레어 세트를 평가한다.
- `cm-worker.mjs`는 선택 부모와 필요한 추가 계승 후보를 결과 체크리스트에 보존한다.
- `cm-acceleration-ui.mjs`의 목표 영역에 부모·조부모·검색 메모를 연결한다.
- 가격·힌트의 원본/강화형 연결과, 육성 후 실제 확보 상태의 대응을 함께 검사한다.
