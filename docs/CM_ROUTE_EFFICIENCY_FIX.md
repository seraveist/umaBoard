# 이벤트·가속·회복 추천 보완 (2026-11-17)

모델 `cm-post-training-v6`.

이전 7000 SP 예시의 42.5657마신은 에프포리아·마야노의 배타 보상을 함께 선택한 수치다.
실제 획득 가능한 조합의 검증값으로 철회한다. 과거 QA/JSON은 당시 실행 이력이다.

- 원본 레어와 진화의 구매 선행 단계, 기존 습득까지 포함해 이벤트 경로를 검사한다.
- 이벤트별 보상 묶음 중 함께 성립하는 선택지 배정을 탐색한다. 다른 각성/서포트/시나리오 경로가 있으면 동시 획득을 허용한다.
- 실제 힌트로 가격을 계산하며 이벤트 모델의 가정 할인율을 재사용하지 않는다. 이벤트 상태의 임의 4096개 잘림도 없다.
- 검토되지 않은 레어 이벤트 보상은 카드당 1개만 허용하고 결과에 미검증 카드를 표시한다. 이는 정확한 다중 보상 지원을 의미하지 않으며 자료 보완 전 보수적인 제한이다.
- 실제 습득 기록이 이벤트 제약과 충돌하면 기록을 지우지 않고 오류로 알린다.
- 정밀 표본에서 불필요한 스킬 제거와 예산 내 1대1 교환을 거친 표본으로 선별하고 상위32개를 정밀 비교한다. HP 충족을 유지하며 같은 기여면 더 싼 조합을 고른다. 기존 습득한 하위 단계는 업그레이드 제거 후 복원한다.
- 최속 스퍼트 HP가 불충족인 조합은 최초 HP 고갈 거리가 늦은 것을 우선한다. 고갈 뒤 회복으로 결승선 HP만 늘어난 후보에 보상을 주지 않는다.
- 제한된 반복 탐색이며 전역 최적해를 보장하지 않는다. 회복 실패 확률이나 HP 고갈에 따른 실제 스퍼트 지연은 여전히 모델 범위 밖이다.

정밀 추가/제거/교환 재평가는 최대256개이며 한도 도달은 refinementLimited로 기록하고 완료로 표시하지 않는다.
