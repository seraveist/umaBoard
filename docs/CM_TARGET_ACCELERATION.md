# 육성 전 목표 가속과 레어 세트 — v2 (2026-11-17)

1차 마신표 하단에 추천 가속 조합과 카드별 확보 레어 세트를 제공한다.
계승기가 포함되면 제공 우마무스메의 **정확한 의상 초상·이름**을 표시한다.
추천은 실제 획득·습득 기록을 변경하지 않는다.

부모 조합·프렌드 인자 검색 기능은 사용자 요청으로 현재 범위에서 제외했다.
[관련 설계](CM_INHERITANCE_PREPARATION.md)는 보류 기록으로만 남긴다.

## 계산 계약

- 개별 마신표 모델은 `cm-first-chart-v5`, 목표 추천은 `cm-target-acceleration-v2`,
  최종 구매 추천은 `cm-post-training-v8`이다.
- 목표는 시나리오 기본 상한·최상 의욕·적성A·본체 고유기를 기준으로 한다.
  모든 미지불 구매 단계에 힌트Lv5와 할인 특성 없음을 적용한다.
  육성 전 총SP 예산을 예측하거나 전체 구매를 확정하지 않는다.
- 표시용 Top10 이전의 전체 후보를 사용한다. 추천 계승기가 Top10 밖이면
  같은 체크리스트에 `목표 가속 계승`으로 추가한다.
- **계승은 속도·가속·복합·강화형을 합쳐 최종 최대6개**다. 가속 추천의 계승도
  같은 한도를 사용한다. 본체 고유기는 계승 개수에 포함하지 않는다.
  화면에 목표 계승 사용 칸과 남는 칸을 표시한다. 기존 기록과 목표를 합쳐6개를
  넘으면 교체할 개수를 안내한다. 최종 입력·구매 조합에서도6개 제한을 검사한다.
- 각성·시나리오 진화, 구매 단계, 계열 중복, 이벤트 배타, 대체 경로와 시나리오
  진화2개 제한을 함께 검사한다.

## 강화 계승과 실제 가격

- 에피파네이아 `901411 → 91101411`, 스테이 골드 `901351 → 91101351`은
  강화형의 효과에 원래 계승형의 검증된 구매 단계를 연결한다.
- 원래 계승형과 강화형의 비용을 두 번 청구하지 않는다. 화면에 입력한 강화형의
  실제 힌트가 우선하며, 이미 구매한 단계는 남은SP에서 다시 청구하지 않는다.
- 과거 일반 계승ID로 저장한 힌트·습득 기록은 현재 강화형 행에 명시적 기록이
  없을 때 복원한다. 현재 행에서 미획득으로 바꾼 기록을 덮어쓰지 않는다.
- 가격 미확인 가속은 무료로 평가하지 않고 제외 내역을 반환하며 화면에 개수를 표시한다.
- 보유·직접 부모 등 강화 조건은 기존 1차 마신표의 조건 충족 가정이다.
  이 변경에서 실제 부모·보유 목록 입력 기능을 추가하지 않는다.

## 종반 기여와 같은 순위에서의 효과

- 종반에 가속이 발동하거나 지속시간이 종반 진입에 닿아야 목표 후보가 된다.
  후반의 속도·가속 복합기가 진입속도를 바꾸는 연결 효과도 비교한다.
- 초반 가속이 본체 고유기의 후속 발동 시점을 미세하게 바꿨다는 이유로 종반
  가속이 되지는 않는다. 연결 예외는 후반에 발동한 속도·가속 복합기에만 적용한다.
- 목표 추천과 서포트 보상 비교는 `cm9-fixed-rank-sensitivity-v1`을 사용한다.
  도주1~3위, 선행2~5위, 선입·추입3~9위의 고정 순위를 각각 비교한다.
  각 주행에서는 모든 스킬이 **동일한 순위**를 공유한다.
- 순위에 따라 작동하지 않는 조건 가지를 제거하되, 랜덤 위치를 뽑은 뒤 제거하여
  다른 조건 가지의 난수가 밀리지 않도록 한다. 연결된 후속 효과는 선행 효과의
  실제 발동 여부를 그대로 따른다.
- 순위별24표본·0.01초의 결과를 같은 비중으로 비교한다. 이는 민감도 비교이며
  실제 순위 확률·순위 이동·승률 예측이 아니다. 양립하지 않는 순위의 효과를
  동시에 더하지 않지만, 여러 전개를 대비하는 보험 스킬을 함께 습득하는 것은 허용한다.
- 확률 요소가 없는 주행만 표본 간 계산을 재사용한다. 랜덤 발동·효과량은 유지한다.
- 개별 마신표와 최종SP 최적화의 일반 주행 점수는 기존 조건 충족 가정을 유지한다.
  목표 조합의 순위별 평균과 해당 점수는 서로 다른 비교 전제다.

## SP 효율과 제한 탐색

- 같은 조합의 마신과 전체 구매 비용을 사용한다. 개별 마신을 더하지 않는다.
- 육성 전 목표 점수는 `순위별 평균 마신 − 구매SP × 0.15 / 100`이다.
  **추가100 SP당0.15마신**은 과한 보험 가속을 줄이기 위한 준비 단계의 정책값이며,
  게임에서 측정한 법칙이나 승률 환산값이 아니다. 함수 옵션으로 조정할 수 있다.
- 최대 목표 점수와0.01 이내인 안에서는 더 저렴한 조합을 선택한다.
  v1의 `최대 마신 대비3%·0.10마신` 제한을 그대로 사용하지 않는다.
  비교한 최대 마신안 대비 실제 손실과 효율 정책을 JSON·화면에 남긴다.
- 거친 탐색은 순위별3표본·0.05초, 후보 목표24개, 폭4와 저비용 상태2개,
  빔 탐색 평가 기준360이다. 작은 후보9개 이하는 부분집합을 검사한다.
- 완성 조합의 탐색 시작점을 추가하고6회 추가 깊이 제한을 제거했다.
  **일반 가속 개수에는6개 제한이 없다. 계승만 합계6개 제한**이다.
- 마지막에 전체 가속 단독 후보의 추가와 현재 스킬의 제거를 거칠게 재검사한다.
  추가 상위16개·제거안과, 교체 후보12개/제거6개에서 목표점수 상위8개 및
  동급 저비용 상위8개를 정밀 비교한다. 최대4회·추가 정밀96평가의 제한 탐색이다.
- `closureComplete`는 정밀 비교한 이웃 후보에서 수렴했다는 뜻이다. 모든 교체나
  전역 최적성을 증명하지 않는다. 계산 한도 도달은 별도 필드와 화면에 표시한다.
  총 평가 수에는 추가·제거·교체와 레어 세트 평가가 포함되므로360을 넘을 수 있다.

## 서포트 레어 세트

- 목표 가속을 확보하는 배정을 우선한다. 다른 카드·각성·시나리오로 확보할 수
  있으면 특정 카드의 세트를 불필요하게 강제하지 않는다.
- 같은 목표와 순위 비교 기준에서 보상 묶음의 추가 마신을 비교한다. 함께 받은
  레어는 구매 가능 후보이며 구매 고정이 아니다. 남는 시나리오 진화도 제한 안에서 비교한다.
- 여러 카드의 세트를 폭4로 함께 비교하고 마지막 배정은 정밀 표본으로 평가한다.
  평균 차이0.01 이내에서는 기존 전방 순위 조건의 중반 보강·SP 보조 기준을 사용한다.
- 자료는 동시 레어 묶음과 배타 관계만 관리한다. 다중 레어SSR73장 모두 포함하며,
  기존 상세8장과 추가66장으로 등록 카드74장이다.
- 공개 원본: GameTora `training_events/ssr.fa74f9c4.json`, `dict/evrew.a687fca9.json`.
  `scripts/import_support_rare_sets.py`로 재현하고 파일 해시·확인일을 보존한다.

## 실제 육성 결과와 연결

최종 단계의 `확보한 목표 가속 유지`는 기본 선택이며 해제할 수 있다.
실제로 습득했거나 힌트를 기록한 목표만 유지하고 미확보 목표는 이름을 표시한다.
실제SP·할인으로 다시 계산하며 부족하면 유지 해제 후 재비교를 안내한다.
목표가 이미 구매된 것처럼 기준 주행에 넣지 않고, 동반 레어도 구매 고정하지 않는다.

계승 속도5개를 이미 습득하고 계승 가속1개를 추가하면6개다. 여기에7번째 계승을
더할 수 없다. 일반형에서 강화형으로 연결된 같은 구매 단계는 한 계승으로 취급한다.
