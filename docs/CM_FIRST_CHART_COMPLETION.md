## 후속 개발이 유지할 계약

- 설정, 보유 의상 정보, 획득 기록을 현재 브라우저 저장 공간에서 이어받는다.
  아이콘만 바뀌면 기록을 유지하고, 의미 있는 계산 데이터 변경은 버전을 구분한다.
- `owned`는 이미 습득, `unavailable`은 미획득, `0`–`5`는 미습득 힌트다.
  화면 필터와 관계없이 같은 전체 체크리스트 상태를 사용한다.
- 상·하위 및 진화 분기 관계는 검증된 구매 단계와 진화 규칙을 사용한다.
  같은 이름·아이콘·표시 그룹만으로 습득 관계를 만들지 않는다.
- 1차 마신표의 후보·계승Top10·마신값을 체크 조작으로 다시 계산하지 않는다.
  계승 확보 최대6개 규칙과 상하위·분기 불변조건을 계속 유지한다.
- 내보내기는 설정, 실제 데이터·모델 버전, 계산 기준, 후보별 마신값,
  획득 상태와 선행 스킬 ID를 제공한다. 후속 단계는 이 의미를 보존해 연결한다.

기존 계산 가정과 한계는 [계산 계약](CM_FIRST_CHART.md)을 유지한다.

가정한다. 이는 실전 승률이나 모든 게임 수식의 검증 완료를 뜻하지 않는다.
