## 왕수·군림의 해석과 외부 자료 대조

이번6개 추천은 모두 왕수 계열을 선택했다. 금색은 니가타500SP 및 세 코스800SP,
백색은 주쿄·한신500SP다. 이 사실만으로 과대평가가 확정되는 것은 아니다.
새로 읽은 [신게임 공략의 왕수 해설](https://kamigame.jp/umamusume/page/277963970265014629.html)은
도쿄2000·롱샹 외에도 도쿄2400·한신2000을 약10~20m 지연의 준최속 가속으로 평가한다.
반면 교토 등의 더 늦은 발동에는 낮은 우선도를 제시한다.
2024년3월의 [Flosche 원작성 준비 메모](https://note.com/flosche/n/nfe35049e4af7)도
주쿄 잔디2000의 유효 가속으로 왕수·군림을 각각 열거한다.
후자는 마ンスリーマッチ 자료이며 CM 실측 자료로 바꿔 부르지 않는다.

따라서 **왕수는 도쿄·롱샹 밖이면 항상 오답이라는 기준은 적절하지 않다.**
코너와 종반의 교집합·남은 거리·각질·순위·발동 당시 가속 여지를 함께 판단해야 한다.
위 두 글은 정성적 코스 판단 근거이며 실전 발동률을 보정할 표본 수·모집단 자료는 제공하지 않는다.
검색에 잡힌 다른 종합 표는 현재 본문이 동적 순위·진단 자료로 바뀌어 검색 발췌의 확률표를 재현하지 못했다.
그 발췌 확률은 검증 근거에 넣지 않았다.

실제 왕수·군림 서포트`30161`·`30250`을 편성하고 금/백4종을 각각 단독 비교했다.

## 유지된 검증과 판정의 한계

- 고정 운영 커밋의 [원격 CI](https://github.com/seraveist/umaBoard/actions/runs/44252470665)는 완료·성공이다.
  기존 전체 검사는 Node289개·Python51개다. 이번 재점검에서 이 전체 검사를 다시 실행한 수치로 쓰지 않는다.
- 이번에 발동·물리·상태 관련 회귀 검사87개를 다시 실행했고87개 통과·실패0이었다.

- 이번 원본 대조에서 확인한 공유 난수의 스킬별 범위와 상세 발동ID 조회는 고정 원본의 구현과 같았다.
  의심만으로 새로운 버그로 분류하지 않았다.
- 기존의 경사/직선 추첨 출처 차이·전력 스퍼트 근사·큰 후보군 제한 탐색은 계속 한계다.
  전개 실측을 제외해도 후보 보존과 참조 시점의 정합성은 추가 보완할 수 있다.

권장 순서는 **후보 보존과 실제 입력 재해석 → 전력 스퍼트 조건 참조 시점 통일 → 같은 반례와 새 조합 재검증**이다.
후보 수를 더 많이 탐색해도 최초 수집 단계에서 사라진 스킬은 찾을 수 없으므로 후보 전달부터 고쳐야 한다.
현재는 조건을 명시한 비교 도구로 활용할 수 있지만, 모든 실제 입력의 완전한 구매 추천이나
실전 발동률·승률의 정확도를 보장하는 상태로 설명하면 안 된다.

## 재현

[고정 v10 재점검 도구](../scripts/audit_cm_v10_reliability.mjs)는 운영 해시·데이터 버전을 먼저 확인한다.
참조 시점 변형은 무시 경로인 `.cache/v10-reaudit` 안에만 생성하며 운영 assets는 덮어쓰지 않는다.
이번 감사 결과는 과거 v10 결과와 별도 파일로 보존했다.

```powershell
node --test tests/cm-v10-mechanics.test.mjs tests/cm-activation-probability.test.mjs tests/engine.test.mjs tests/cm-state.test.mjs
node scripts/audit_cm_v10_reliability.mjs --candidates --clock
node scripts/audit_cm_v10_reliability.mjs --bounded
node scripts/audit_cm_v10_reliability.mjs --conditional
```

운영 수정 후에는 기존 고정 해시 검사를 무작정 바꾸지 않고 이 버전의 재현 기록을 보존한 상태에서
새 버전의 입력·결과를 따로 만들어 비교해야 한다.
