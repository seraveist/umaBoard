# 진화·시나리오 스킬 검증 — 2026-11-17

사용자 선택에 따라 **진화 조건 충족 가정**을 유지한다. 실제 스탯·보유 스킬로
진화 해금 여부를 새로 판정하지 않는다. 연결, 원본 효과, 획득 경로, 진화 제한과
그에 따른 후보·비용·최종 조합을 검증했다.

## 확인 범위와 수정

- 진화 연결 691건: 의상 진화 638건, 시나리오 진화 53건. 모두 원본 레어 하나에
  연결되며, 소유 의상/시나리오가 일치하고 레어 획득 경로가 있을 때만 후보가 된다.
  다른 의상·시나리오의 진화는 유입되지 않는다.
- 기존에는 시나리오15의 2개 제한만 있었다. 시나리오7~14에도 각각 최대2개를
  등록했다. 캐릭터 각성 진화는 이 제한에 포함하지 않는다. 2개 습득 후 세 번째를
  추가 추천하지 않으며, 3개를 습득한 잘못된 기록은 오류로 반환한다. 여러 진화를
  미습득 힌트로 기록하는 것은 가능하다. 기존 기록을 임의로 삭제하지 않는다.
- 시나리오7~14의 보상 경로 **124건을 검토·등록**했다. 그중23건은 기존 무조건
  태그를 편성 조건이 있는 경로로 대체한 것이며,101건은 누락 보완이다. 전체
  시나리오 경로는125→226건이다. 고정 보상, 종료 보상, 링크 캐릭터의 레어/일반,
  BC 레이스 및 라멘 선택 보상을 포함한다.
- 링크 캐릭터는 육성 의상 또는 편성 서포트의 캐릭터로 확인한다. 카드 희귀도를
  캐릭터 신원으로 오인하지 않는다. 레전드의 `機先の勝負/序盤巧者`는 그룹 카드
  `伝説の体現者`의 실제 편성으로 분기한다. 메카 라이츠와 라멘 타즈나&하로의
  고정 선택지를 다른 캐릭터의 편성 조건과 혼합하지 않는다.
- 검토한 경로에는 출처·확인일을 보존한다. 조건 없는 원본 `sce_e` 태그가 같은
  스킬의 검토된 링크 조건을 우회하지 않도록 교체한다. 추가 경로만 있는 시나리오도
  정규화 결과에 등록하고, 출처 없는 검토 경로·미지원 조건은 검증에서 차단한다.
- 스킬 효과 및 구매 단계 데이터는 이전 번들과 동일하다. 새 힌트 최대치를
  추정하지 않는다. 최종 구매는 실제로 기록한 힌트를 사용하고, 진화는 원본 레어
  구매 단계를 공유한다. 원본을 습득했다면 추가 진화SP는0이다.

## 효과 검증과 계산 수정

고정된 UmaTools/umasim 스킬 원본을 비교했다. 진화691건 모두 두 원본에 있으며
발동 조건과 사전 조건은 일치한다. **시나리오 진화53건은 효과 종류·수치·지속시간도
전부 일치**한다. 전체 진화 중625건은 이 항목 전체가 그대로 일치한다. 나머지66건의
원시 차이는 즉시/패시브 지속시간 표현(-1 대0)43개 invocation 및 효과36개
invocation에 있다(일부 중복). 시야·다른 주자 대상 효과가 두 번째 원본에 생략된
경우 등을 포함하므로 이를 임의의 수치 변경 근거로 쓰지 않았다.

별도로 계산 문제를 재현했다. `湯切りの妙技`의 중거리·전 능력치1000 이상 강화
효과와 기본 효과가 같은 `phase_random==1`을 별도로 표본 추출하여,24표본 중
일부에서 기본 효과가 먼저 발동했다. 원본 시뮬레이터는 같은 스킬의 동일 무작위
조건을 캐시해 공유한다. CM 표본도 무작위 조건 키를 공유하도록 수정했다.
계산 모델은 `cm-first-chart-v3` / `cm-post-training-v3`으로 변경했다.

999/1000 경계에서24표본 모두 강화/기본 효과 중 해당하는 하나만 발동하는 것을
검증했다. 이는 스킬의 **주행 효과 분기** 판정이며, 진화 해금 조건 판정과 구분한다.

## 저장과 회귀 검증

경로·제한 보정 시 스킬 효과·구매 단계·연결·의상·서포트·코스가 같으면 이전
저장 버전을 호환 목록에 남긴다. 마신표 재생성 시 같은 편성·경기 설정의 습득
기록, 실제 스탯/SP/적성/할인 특성을 복사한다. 원본 계획은 변경하지 않는다.
새 버전의 입력이 있으면 그것을 우선하고, 다른 시나리오·편성 또는 효과/가격이
바뀐 데이터는 자동 이관하지 않는다. 이전 추천값은 다시 사용하지 않는다.

- Node188개, Python45개 테스트 통과(총233개).
- 전체2229스킬 정렬,1085상하위 연결,2340방향별 진화 분기 전환 회귀 포함.
- 추가 검증:691진화 소유 범위·가격 공유,9개 시나리오 풀의 모든2개/3개 조합,
  링크 경로의 본체/SSR/SR/R 신원,그룹 편성,시나리오 간 격리,출처 표시,
  습득 진화 잠금과 최종 추천 상한,저장 이관 및 부적합 이관 차단.
- 실제 브라우저1440px에서 이전 버전 저장 키의 습득 기록·공부가·실제 스탯·SP·
  적성 이관과 최종 추천을 확인했다. 원본 계획 유지, 재접속 후 기록 복원,
  390/340px의 기록·결과 전환과 가로 넘침 없음, 페이지/파일 오류0건을 확인했다.
  예시500 SP에서328 SP 사용·172 SP 잔여이며, 이미 습득한 단계는 재청구하지 않았다.

## 확인하지 않은 범위

획득 이벤트의 실제 발생·선택 이력이나 진화 해금 달성을 증명하지 않는다. 서로
다른 이벤트 선택지의 보상을 모두 받았다고 자동 기록하지 않는다. CM의 실제
구매 가능 여부와 힌트는 사용자가 입력한다. 원본 데이터와 경로 목록 전체의
완전성을 선언하지 않으며, 기존 큐레이션 상태는partial이다.

기존 엔진의 미지원 효과·가변 효과·일부 반복 발동 제외 정책은 유지한다.
진화4종(`大望は煌めきとなりて`, `響け、万雷の喝采よ`, `無比なる六花`,
`雪魄氷姿`)의 효과48은 여전히 미지원이다.29개 진화의 원본 레어12종은 시야·방해
등의 구매 단계 교차 근거가 없어 비용 미검증이며, 추가 구매 추천에서 제외한다.
데이터 연결이 정확하다는 확인을 모든 스킬의 계산 지원으로 해석하지 않는다.
